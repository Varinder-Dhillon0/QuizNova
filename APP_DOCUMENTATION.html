Frontend Features

Attempt Quiz

  • Path: /attempt/:quizId and /preview/:quizId
  • File: client/src/features/AttemptQuiz/index.jsx
  • Context: QuizContext created with createContext()
  • Loading states: isLoading, QuizNotFound, QuizAlreadySubmitted
  • Subcomponents: StartQuiz, Question, Navbar, QuizNavigation, SubmitQuiz, Popup
  • Hooks: useFetchQuiz, useUpdateServerResponse in client/src/features/AttemptQuiz/api/useQuizApi
  • Timer logic: calculateRemainingTime() from client/src/helpers/calculateRemainingTime.jsx
  • Auto sync: mutations to backend /response/update via axios and @tanstack/react-query

Quiz editor / creation

  • Editor: client/src/features/Editor
  • Quiz manager: client/src/features/createQuiz/QuizManager.jsx
  • Routes: /admin/editor/:workspaceId/:quizId, /admin/dashboard/create/:workspaceId
  • APIs: /quiz/create, /quiz/update, /quiz/delete, file upload endpoints

Dashboard / Responses

  • Dashboard root: client/src/features/Dashboard/index.jsx
  • Quiz responses: client/src/features/Dashboard/components/quizResponses.jsx
  • Router wraps Dashboard and subviews for schedule and results

Authentication

  • Paths: /login, /register
  • Files: client/src/features/auth/login.jsx, client/src/features/auth/register.jsx
  • Hooks: useAuth from client/src/hooks/useAuth.jsx
  • Google login: client/src/features/auth/googleLogin.jsx

Shared utilities

  • client/src/shared/components: popup, loaders, pageNotFound, etc.

Backend Architecture

Entrypoint

  • server/index.js: sets up Express, JSON, bodyParser, CORS, static uploads, db connect and routes
  • CORS allowed origin: http://localhost:5173
  • API base: http://localhost:5000

MongoDB

  • server/utils/mongodb.js exports connectDb
  • Schemas: server/schema/*.js for users, workspace, quiz, response, result, userVerification

Routes

  • server/routes/users.js: user sign in/up and verification paths
  • server/routes/workspace.js: workspace management endpoints
  • server/routes/quiz.js: quiz endpoints plus file upload and image management
  • server/routes/response.js: quiz response CRUD and results generation

API endpoint summary

MethodPathDescription
GET/Health check, returns JSON
GET/quiz/getList quizzes
GET/quiz/getQuizGet quiz by id
POST/quiz/createCreate quiz (multipart with quizThumbnail)
POST/quiz/updateUpdate quiz (multipart with quizThumbnail)
POST/quiz/deleteDelete quiz
POST/quiz/ques/updateUpdate question(s)
POST/quiz/ques/uploadImageUpload question image
POST/quiz/ques/deleteImageDelete question image
GET/response/getGet response record
POST/response/createCreate new response
POST/response/updateUpdate response in-progress
POST/response/resultsGet results list
POST/response/singleresultGet one result by responseId
POST/response/generateresultGenerate and save result

File uploads

  • Storage path: server/uploads/{creator}/{workspace_id}/ for quiz thumbnails, and .../{quizId}/{queId}.* for question images
  • Routes manage file naming, directory creation, and deletion using node fs
